<br>文 / 西打藍 Siddharam<br><br>

今年 3 月，<br>
我報名了一堂實體水電課，<br><br>

這是為了我的包租代管事業，<br>
方便修繕房屋，<br>
而上的課。<br><br>

然而我在課堂上，<br>
實在難以專心，<br>
於是打開電腦，<br>
玩了想摸索許久的工具：<br><br>

Claude Code。<br><br>

結果一發不可收拾。<br><br>

我整場水電課都沒在聽，<br>
還買了 Claude 付費版，<br>
在終端機上做各種試驗。<br><br>

最後我確信，<br>
這是今年最有潛力的強大槓桿。<br><br>

我按照時序，<br>
分享接下來，<br>
我怎麼玩 Claude。<br><br>


<h3 class="article-h1-color">▎最初怎麼應用？</h3><br>

一開始，<br>
我翻了以前的靈感庫，<br>
找到想做，但拖延許久的小工具：<br>
「基隆美食抽籤」<br><br>

我每天在基隆，<br>
最常思考的問題，<br>
就是「今天要吃什麼？」<br><br>

於是用 Claude 做了一版，<br>
發現它可以快速生成網站，<br>
不過要親自給精準資料，<br>
邏輯和開發網站很像。<br><br>

接著，<br>
我請它每天早上 10:00，<br>
收集國外冷門商業模式，<br>
給我一些啟發。<br><br>

玩著玩著，<br>
我決定做一件，<br>
突破自我限制的事：<br><br>

找夥伴。<br><br>


<h3 class="article-h1-color">▎AI 小隊</h3><br>

今年 3 月底，<br>
我約了 2 位朋友碰面。<br><br>

1 位是曾找我諮詢的學生，<br>
他平常在國外數位遊牧，<br>
足跡遍佈愛爾蘭、泰國、越南，<br>
是開朗、感性，執行力很高的人。<br><br>

另 1 位是曾在活動認識的朋友，<br>
他有開一間行銷公司，<br>
外語能力強，有多重興趣，<br>
是工作能力極強的人。<br><br>

我們的共同點，<br>
是 3 人都正在玩 Claude，<br>
見面後一拍即合，<br>
開始合作。<br><br>

我們約定每週開會，<br>
一次走多條路線，<br>
開發不同類型產品。<br><br>

目前已經完成 3 項產品，<br>
其中 2 個的目標市場是國外，<br>
先分享另一項產品。<br><br>


<h3 class="article-h1-color">▎Claude Code 新手村</h3><br>

我在玩 Claude 的過程中，<br>
發現它的潛力後，<br>
也想分享它給其他事業合夥人。<br><br>

於是我做了一套 Claude Code 新手村，<br>
用互動遊戲的方法，<br>
快速教人學會 Claude 基本操作。<br><br>

為了讓教學更完整，<br>
我甚至買了一台 Windows 筆電，<br>
特地為不同習慣的工作者，<br>
規劃有效教學。<br><br>

在研發過程，<br>
我還跟 Claude 一起建立會員系統，<br>
也串了信用卡、Apple Pay、ATM 等金流方案。<br><br>

我也開放這套互動教學，<br>
給幾位親友試用。<br>
大家都順利安裝 Claude，<br>
並做出自己的小作品網站。<br><br>

其中有幾位太喜歡，<br>
也主動付費升級。<br><br>

近期，<br>
我又用 Claude 大幅更新官方網站。<br><br>


<h3 class="article-h1-color">▎官網大翻新</h3><br>

我有個拖延許久的事，<br>
就是定期更新官網。<br><br>

官網中有許多日常更新：<br>
諮詢案例、網站案例、演講歷程、自我介紹。<br><br>

因為是自己寫的程式，<br>
每次更新都很麻煩，<br>
需要理解程式碼、手動改資料、上傳，<br>
才能更新。<br><br>

直到生日那週，<br>
我反思自己事業瓶頸時，<br>
忽然驚覺這件一直無法放手的事。<br><br>

於是我決定交由 Claude 重構，<br>
官網程式碼，全部重寫。<br><br>

此外，<br>
我還新增公司的後台系統，<br>
包含：<br><br>

案件管理、支出紀錄、報價單系統、<br>
待辦清單、寫作靈感、流程知識庫、罐頭訊息。<br><br>

我還額外做了常用工具庫，包含：<br>
PDF 編輯器、圖片掃描轉 PDF、圖片批次壓縮。<br><br>

最後，<br>
我也把電子報訂閱，<br>
嵌入在官方網站中。<br><br>

還沒結束。<br><br>

我近期正在做一套會員系統，<br>
以及數位產品上架功能，<br>
終於做了拖延好久的各種事。<br><br>

在玩 Claude 的過程，<br>
也讓我其他事業一起升級了。<br><br>


<h3 class="article-h1-color">▎遍地開花</h3><br>

我發現 Claude 不只能開發網站，<br>
還能建立 APP，<br>
這是我正在醞釀的小專案。<br><br>

我的包租代管事業，<br>
官網已經搭建完成，<br>
甚至還做了冷氣經銷的頁面。<br><br>

我最近去一間溫泉飯店談合作，<br>
打算用 Claude 協助重構內部管理系統。<br><br>

額外透露一個小彩蛋，<br>
8/22（六）的閱讀串門子活動，<br>
我會分享一個「線上書友互動小遊戲」，<br>
效果非常驚艷。<br><br>

如果説去年，<br>
是包租代管事業改變了我，<br>
今年的主軸，絕對是 Claude。<br><br>


<h3 class="article-h1-color">▎全面升級</h3><br>

訂閱 Claude 的月費，<br>
我從 600 元，<br>
已經升級到約 3000 元。<br><br>

有了它以後，<br>
我做到以前需要數百萬、<br>
甚至數年才能做到的事。<br><br>

然而我在社群上看見的，<br>
多數專業工作者，<br>
僅用它來產文、產圖，<br>
還沒充分運用它的最強潛力。<br><br>

這讓我激起一個，<br>
自己醞釀好幾年的想法。<br><br>


<h3 class="article-h1-color">▎共學營</h3><br>

我一直有一個，<br>
想要舉辦黑客松的念頭：<br><br>

大家帶著點子來，<br>
身邊有一群同樣熱情的人，<br>
各自在現場開發，<br>
同時也能相互交流。<br><br>

而最後，<br>
則分享今天的成果。<br><br>

我超想看見這幅畫面。<br><br>

於是我和夥伴討論後，<br>
決定 2026.08.23（日）14:00-17:30，<br>
舉辦一場 Claude Code 共學營。<br><br>

這是入門款的活動，<br>
我會展示迄今做過的網站、系統，<br>
2 位夥伴也都到場。<br><br>

此外，<br>
如果你是完全不懂的小白，<br>
我會帶你入門 Claude Code，<br>
一起成為創造者。<br><br>

如果你已經熟悉 Claude 了，<br>
則可以到場開發，<br>
最後在和大家交流。<br><br>

這場收 25 人，<br>
目前約剩 10 個名額，<br>
請點擊「活動連結」報名。<br>
折扣碼：SIDDBLUE10<br><br>

不確定何時會辦下一次，<br>
如果你還沒玩 Claude Code，<br>
也想入門很久，<br>
非常歡迎來這場活動，<br>
突破你的思維上限。<br><br>

這或許會是你人生中，<br>
獲得過的最強槓桿。<br><br>

1. 列點文（Listicle）
目標： 讓讀者覺得「內容超豐富，先收藏再說」。

架構：

吸睛標題： [數字] + [特定族群] + [渴望的成果/解決的痛點]。

開場導言： 點出目前大家遇到的困難，並承諾這份清單能省下多少時間。

核心清單： * 小標題（必須帶有動詞或具體好處）。

短評（1-2 句解釋為什麼這個點很重要）。

彩蛋/總結： 清單結束後，多給一個「進階建議」或「最強的一個點」。

CTA： 詢問「你最喜歡哪一個？」或「還有什麼是你推薦的？」。



2. 打臉文（Counter-Intuitive）
目標： 戳破讀者幻想，重建權威感。

架構：

陳述平庸觀點： 寫出大家普遍相信的「溫情屁話」（例：努力就會成功）。

暴力否定： 用一句話直接推翻（例：這是我聽過最危險的謊言）。

揭露殘酷真相： 透過數據、案例或大師觀點，解釋為什麼舊觀點行不通。

提出新邏輯： 給出一套更現實、更有競爭力的替代方案。

收尾： 提醒讀者，清醒才是變強的開始。



3. 教學文 / 攻略文（How-to Guide）
目標： 建立「專家」形象，讓讀者產生「照著做也會成功」的錯覺。

架構：

成果展示： 先放上亮眼的成績單（例：我如何用一個月達成...）。

工具/環境準備： 列出達成此成果所需的硬體或心態。

SOP 拆解： 將複雜過程切分為 3-5 個清晰步驟。（重點：步驟要夠具體）

避坑指南： 告訴讀者我在哪裡失敗過，幫他們避開那些坑。

鼓勵行動： 告訴讀者「現在就開始」，別只看不做。



4. 故事文 / 側寫文（Storytelling）
目標： 透過人物代入感，偷偷植入你要銷售的價值觀。

架構：

人物登場： 介紹一個具備特定屬性的人（例：我的特助、那個 SEO 專家）。

衝突/誤解： 我原本對他的看法，或是他遇到的巨大挑戰。

關鍵轉折： 發生了一件事（或一段對話），徹底改變了局勢。

價值提煉： 透過這個故事，我悟出了什麼樣的商業/人生道理。

情感對接： 將這個道理連結到讀者的生活。



5. 觀點評論（Curated Opinion）
目標： 借用別人的流量，建立自己的品味。

架構：

熱點引入： 提到最近最火的影片、新聞或大師觀點。

重點摘錄： 幫讀者做功課，整理出 3 個最有價值的金句或論點。

個人解讀： 這是最重要的部分。你怎麼看這些論點？在你的領域如何應用？

落地應用： 告訴讀者這對「現在的你」有什麼實際影響。

互動誘餌： 「你認同這個觀點嗎？在下面留言告訴我。」

🚀 故事銷售文章：萬用五段式架構
第一階段：【極致衝突與自黑】—— 鉤子（The Hook）
心法： 承認一個令你丟臉、焦慮或感到挫敗的瞬間。這能瞬間拉近讀者距離，打破「大師」的隔閡。

寫作要點：

開場第一句就拋出巨大的損失或尷尬的失敗。

承認自己的偏見（如：我覺得吳淡如很犀利、我覺得數位遊牧不穩）。

金句範例： 「我以為我懂管理，直到我被自己的特助當場上了一課。」



第二階段：【意外的發現】—— 震撼（The Shock）
心法： 透過一個具體的行動（買書、面試、看影片、辦簽證），發現一個與原先認知完全相反的事實。

寫作要點：

使用大量數據或硬核細節（140本書、0件急事、德國藝術家簽證）。

營造「物理性」的震撼感（包裹堆滿屋、手機完全失聯）。

金句範例： 「當我翻開那張表格，我才發現我引以為傲的產出，竟然不到人家的 1%。」



第三階段：【底層邏輯拆解】—— 覺醒（The Insight）
心法： 引用一位「世界級權威」或「科學理論」來解釋這個震撼事實。

寫作要點：

引入外部權威（Alex Hormozi, Naval, 馬斯克, 賈伯斯）。

提出一個視覺化的隱喻（一碗彈珠、穿黑皮衣、剝洋蔥）。

重新定義成功：成功不是因為做了什麼，而是因為「拒絕」了什麼。

金句範例： 「真正的強者不是搭上熱潮，而是他一直在那裡，等熱潮搭上他。」



第四階段：【建立防火牆機制】—— 落地（The Solution）
心法： 告訴讀者這不只是觀念，而是一套可以執行的「機制」。

寫作要點：

強調**「外包/工具/制度」**的重要性（AI、特助、拒絕溝通、思考週）。

對抗「酸民/雜音」：承認身邊人會反對，但你要站在「主場」思考。

金句範例： 「把醜話說清楚，是為了保護後面的自由。」



第五階段：【收尾與行動導引】—— 昇華（The CTA）
心法： 不直接求買單，而是展現一種「嚮往的生活型態」，並留下互動誘餌。

寫作要點：

用一個哲學高度的金句收尾。

P.S. 區域：指派一個具體任務或身分（如：我的特助會回你）來引發互動。

金句範例： 「殺掉平庸的機會，只留那一件事。專注，就是解答。」
