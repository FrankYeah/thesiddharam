<br>文 / 西打藍 Siddharam<br><br>

我這週參加一場活動，<br>
忽然被邀請短講 15 分鐘，<br>
若是你，你會上台嗎？<br><br>

我心裡跑過萬千思緒，<br>
猶豫幾分鐘後，<br>
決定答應。<br><br>

為什麼？<br><br>

一來，我剛好隔天有演講，<br>
簡報已經準備好。<br><br>

二來，現場有我想認識的人，<br>
想趁機展現自己。<br><br>

然而，這 2 個原因，<br>
是我後來才想到的。<br>
在現場時，我沒想那麼多，<br>
憑藉一股直覺答應了。<br><br>

最終成果很好，<br>
會後也認識幾位朋友。<br><br>

當時，我為何信任直覺，<br>
就這樣臨時答應了？<br><br>

因為發生幾件事，<br>
讓我越來越相信直覺了。<br><br>

我舉例：<br><br>


<h3 class="article-h1-color">▎一、第一次的廣告投放</h3><br>

我從沒投過廣告，<br>
擁有的廣告知識也不多。<br><br>

但就在 2 週前，<br>
內心忽然有股聲音說：<br>
「投投看廣告吧。」<br><br>

我馬上聯繫身邊最強的廣告投手，<br>
拜託他介紹投手認識，<br>
結果朋友竟然直接幫我。<br><br>

結果，成效很好，<br>
我也跟 AI 一起學投放技巧，<br>
從實戰練習。<br><br>

這份直覺的禮物，<br>
讓我快速學會這時代的重要工具，<br>
而下一件事也一樣。<br><br>


<h3 class="article-h1-color">▎二、Claude Code 集訓班</h3><br>

我 11 月份的 Claude Code 集訓班，<br>
已經額滿了。<br><br>

而這是我 10 月初，<br>
在舉辦 30 人共學營時，<br>
忽然冒出的想法：<br><br>

「既然我的教學方式有效，<br>
那要不要規劃完整課程，<br>
讓學員一次學會 Claude Code 的精髓？」<br><br>

我很快聽從內心聲音，<br>
開始準備課綱、說明頁，<br>
並找人來測試，<br>
以及進行第一場直播分享。<br><br>

一個月後，<br>
11 月場次超額滿班，<br>
1 月場次也有 13 人報名了。<br><br>

我漸漸感受到，<br>
直覺送給我的禮物。<br><br>

分享最後一個例子。<br><br>


<h3 class="article-h1-color">▎三、數位講座</h3><br>

集訓班能誕生，<br>
其中一個關鍵，<br>
是因為我 9 月舉辦的一場，<br>
成功的線上收費分享會。<br><br>

我永遠記得那個數字：<br>
121 人參加。<br><br>

那是我第一次舉辦 Claude Code 分享會，<br>
分享我用它做的各種系統，<br>
如何幫助我的工作。<br><br>

為何會辦這場活動？<br>
因為某天洗澡時，<br>
心裡有股聲音說：<br><br>

「應該蠻多人想聽，<br>
你是如何使用 Claude Code 的，<br>
去辦線上分享會吧。」<br><br>

於是我聽進去，<br>
並照做了。<br><br>

而每一次的照做，<br>
都讓我更往前一步。<br>
例如最近，我又聽見另一股聲音。<br><br>


<h3 class="article-h1-color">▎新的直覺</h3><br>

最近，<br>
我的直覺又有新想法，<br>
要我在社群上，<br>
更多分享跟 Claude 做的事。<br><br>

但可能用另一種形式，<br>
而非在現在的帳號。<br><br>

快的話，下週我就會做。<br><br>

以前的我，可能會懷疑：<br>
「確定要做嗎？」<br><br>

但有過近期經驗後，<br>
我知道，<br>
就是要做，不用考慮。<br><br>

同時，<br>
我也找到「誕生直覺」的路徑。<br><br>


<h3 class="article-h1-color">▎直覺，需要專注醞釀</h3><br>

我 95% 的時間，<br>
都是用理性工作。<br><br>

但我發現，<br>
若要發揮更多直覺，<br>
你需要準備一件事：<br><br>

「看見你真正的問題是什麼？」<br><br>

例如開頭分享的，<br>
我會答應臨時上台分享，<br>
其中的原因，<br>
是我也在思考：<br><br>

「如何打入這裡的圈子？」<br><br>

結果，邀請一到，<br>
我的直覺搶先一步，<br>
告訴我答案。<br><br>


<h3 class="article-h1-color">▎直覺，走沒走過的人</h3><br>

邏輯會帶你依循正軌，<br>
適合 1-100 的發展。<br><br>

直覺則會帶你脫離正軌，<br>
突破限制。<br><br>

直覺是一份禮物，<br>
收到時會很驚訝，心想：<br>
「這不合理。」<br><br>

每當這樣的聲音出現，<br>
我就知道，<br>
這很可能又是一件，<br>
拓寬我思維天花板的禮物。<br><br>

直覺要我做的事，<br>
之所以被我認為不合理，<br>
原因就只有一個：「我沒做過。」<br><br>

這是一篇，<br>
來自我這幾個月，<br>
事業大爆發後，<br>
其中一個感想。<br><br>

我還在理清思緒，<br>
慢慢跟你分享。<br><br>

1. 列點文（Listicle）
目標： 讓讀者覺得「內容超豐富，先收藏再說」。

架構：

吸睛標題： [數字] + [特定族群] + [渴望的成果/解決的痛點]。

開場導言： 點出目前大家遇到的困難，並承諾這份清單能省下多少時間。

核心清單： * 小標題（必須帶有動詞或具體好處）。

短評（1-2 句解釋為什麼這個點很重要）。

彩蛋/總結： 清單結束後，多給一個「進階建議」或「最強的一個點」。

CTA： 詢問「你最喜歡哪一個？」或「還有什麼是你推薦的？」。



2. 打臉文（Counter-Intuitive）
目標： 戳破讀者幻想，重建權威感。

架構：

陳述平庸觀點： 寫出大家普遍相信的「溫情屁話」（例：努力就會成功）。

暴力否定： 用一句話直接推翻（例：這是我聽過最危險的謊言）。

揭露殘酷真相： 透過數據、案例或大師觀點，解釋為什麼舊觀點行不通。

提出新邏輯： 給出一套更現實、更有競爭力的替代方案。

收尾： 提醒讀者，清醒才是變強的開始。



3. 教學文 / 攻略文（How-to Guide）
目標： 建立「專家」形象，讓讀者產生「照著做也會成功」的錯覺。

架構：

成果展示： 先放上亮眼的成績單（例：我如何用一個月達成...）。

工具/環境準備： 列出達成此成果所需的硬體或心態。

SOP 拆解： 將複雜過程切分為 3-5 個清晰步驟。（重點：步驟要夠具體）

避坑指南： 告訴讀者我在哪裡失敗過，幫他們避開那些坑。

鼓勵行動： 告訴讀者「現在就開始」，別只看不做。



4. 故事文 / 側寫文（Storytelling）
目標： 透過人物代入感，偷偷植入你要銷售的價值觀。

架構：

人物登場： 介紹一個具備特定屬性的人（例：我的特助、那個 SEO 專家）。

衝突/誤解： 我原本對他的看法，或是他遇到的巨大挑戰。

關鍵轉折： 發生了一件事（或一段對話），徹底改變了局勢。

價值提煉： 透過這個故事，我悟出了什麼樣的商業/人生道理。

情感對接： 將這個道理連結到讀者的生活。



5. 觀點評論（Curated Opinion）
目標： 借用別人的流量，建立自己的品味。

架構：

熱點引入： 提到最近最火的影片、新聞或大師觀點。

重點摘錄： 幫讀者做功課，整理出 3 個最有價值的金句或論點。

個人解讀： 這是最重要的部分。你怎麼看這些論點？在你的領域如何應用？

落地應用： 告訴讀者這對「現在的你」有什麼實際影響。

互動誘餌： 「你認同這個觀點嗎？在下面留言告訴我。」

【我用某個理論/專業手段去測試】：買書、看簽證、設計面試題。

【我發現了一個驚人的反差事實】：她是巨人、她不是不穩、他比想像中更強。

🚀 故事銷售文章：萬用五段式架構
第一階段：【極致衝突與自黑】—— 鉤子（The Hook）
心法： 承認一個令你丟臉、焦慮或感到挫敗的瞬間。這能瞬間拉近讀者距離，打破「大師」的隔閡。

寫作要點：

開場第一句就拋出巨大的損失或尷尬的失敗。

承認自己的偏見（如：我覺得吳淡如很犀利、我覺得數位遊牧不穩）。

金句範例： 「我以為我懂管理，直到我被自己的特助當場上了一課。」



第二階段：【意外的發現】—— 震撼（The Shock）
心法： 透過一個具體的行動（買書、面試、看影片、辦簽證），發現一個與原先認知完全相反的事實。

寫作要點：

使用大量數據或硬核細節（140本書、0件急事、德國藝術家簽證）。

營造「物理性」的震撼感（包裹堆滿屋、手機完全失聯）。

金句範例： 「當我翻開那張表格，我才發現我引以為傲的產出，竟然不到人家的 1%。」



第三階段：【底層邏輯拆解】—— 覺醒（The Insight）
心法： 引用一位「世界級權威」或「科學理論」來解釋這個震撼事實。

寫作要點：

引入外部權威（Alex Hormozi, Naval, 馬斯克, 賈伯斯）。

提出一個視覺化的隱喻（一碗彈珠、穿黑皮衣、剝洋蔥）。

重新定義成功：成功不是因為做了什麼，而是因為「拒絕」了什麼。

金句範例： 「真正的強者不是搭上熱潮，而是他一直在那裡，等熱潮搭上他。」



第四階段：【建立防火牆機制】—— 落地（The Solution）
心法： 告訴讀者這不只是觀念，而是一套可以執行的「機制」。

寫作要點：

強調**「外包/工具/制度」**的重要性（AI、特助、拒絕溝通、思考週）。

對抗「酸民/雜音」：承認身邊人會反對，但你要站在「主場」思考。

金句範例： 「把醜話說清楚，是為了保護後面的自由。」



第五階段：【收尾與行動導引】—— 昇華（The CTA）
心法： 不直接求買單，而是展現一種「嚮往的生活型態」，並留下互動誘餌。

寫作要點：

用一個哲學高度的金句收尾。

P.S. 區域：指派一個具體任務或身分（如：我的特助會回你）來引發互動。

金句範例： 「殺掉平庸的機會，只留那一件事。專注，就是解答。」
