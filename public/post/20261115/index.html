實體課的魅力


文 / 西打藍 Siddharam

11/14 週六，
我辦了首場 Claude Code 集訓班。

這次參與的 20 多人中，
大家幾乎沒用過 Claude Code。
但是在 5 小時課程中，完成了：

安裝 Claude Code
開好 GitHub 程式儲存庫
完成個人網站，網址上線
從 0，學會自動剪片
一半的人，做好 IG 貼文字卡

他們再也不用剪映剪片，
也不需要 Canva 排版貼文。

至於，
為何只有一半的人完成 IG 字卡？

不是學不會，
而是大家忙著美化剪片成果，
沒有乖乖闖關（敲頭）。

週六舉辦的實體課，大成功，
第一天的進度，幾乎每個人都完成。

我想為未來的自己，
整理 3 個實體課成功的關鍵原因：

▎一、讓人真正學會，最重要


課綱完整，是基本，
內容有料，也是基本，
核心關鍵是：
「降低學習門檻，讓人真正學會。」

在實體課中，
我設定每個時段，
都有「必須完成」的進度。

課程內容，
全是遊戲化設計。
學員透過闖關機制，一次一關，
每次動手，都在學習。

我沒有落落長的說明，
而是從第一關，
就要親手做。

有了順暢的學習機制，
接著要讓學習過程好玩。

▎二、團體共學


實體課最特別的環節，
就是有身邊同學。

過程中，我安排：

小組交流
學員成果分享
兩兩拍片認識

5 次的實體課，
可以自由選位，
認識不同朋友，或坐朋友旁邊。

錯過的課，
都能補，
有一位同學開玩笑分享：

「這是逃不了的學習，
又能補課、也有實體，還有線上共學，
想學不會都沒有藉口。」

我們課程中，
有媽媽、上班族、
創作者，甚至退休小學老師，
無論年齡、職業，
都一起共學。

▎三、卡關的安全感


卡關，怎麼辦？

通常線上學習時，
只要卡關，可能就放棄了。

而我的課程，
只要同學反應問題，
課程就會立刻修改進化。

而在實體課中，
我每 5-7 人，
就會配一位助教協助。

我也跟學員說：
「卡住 3 分鐘就求救，別等。」

遇到問題，立即協助解決，
這是實體課，才能有的好處。

▎學習上癮


週六集訓班，
表定 19:00 下課。

但時間一到，
大家依舊捨不得離開，
玩 Claude Code 上癮了。

大家都說：
「Claude 一個月訂閱 600 元，
能有這樣的員工，太便宜了。」

光是第一天學會的剪片，
無論金錢上、時間上，
都大大的回本，
完全是這個世代最大的槓桿。
