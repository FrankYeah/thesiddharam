今年最強大的新槓桿

Claude 改變了我


文 / 西打藍 Siddharam

今年 3 月，
我報名了一堂實體水電課，

這是為了我的包租代管事業，
方便修繕房屋，
而上的課。

然而我在課堂上，
實在難以專心，
於是打開電腦，
玩了想摸索許久的工具：

Claude Code。

結果一發不可收拾。

我整場水電課都沒在聽，
還買了 Claude 付費版，
在終端機上做各種試驗。

最後我確信，
這是今年最有潛力的強大槓桿。

我按照時序，
分享接下來，
我怎麼玩 Claude。

▎最初怎麼應用？


一開始，
我翻了以前的靈感庫，
找到想做，但拖延許久的小工具：
「基隆美食抽籤」

我每天在基隆，
最常思考的問題，
就是「今天要吃什麼？」

於是用 Claude 做了一版，
發現它可以快速生成網站，
不過要親自給精準資料，
邏輯和開發網站很像。

接著，
我請它每天早上 10:00，
收集國外冷門商業模式，
給我一些啟發。

玩著玩著，
我決定做一件，
突破自我限制的事：

找夥伴。

▎AI 小隊


今年 3 月底，
我約了 2 位朋友碰面。

1 位是曾找我諮詢的學生，
他平常在國外數位遊牧，
足跡遍佈愛爾蘭、泰國、越南，
是開朗、感性，執行力很高的人。

另 1 位是曾在活動認識的朋友，
他有開一間行銷公司，
外語能力強，有多重興趣，
是工作能力極強的人。

我們的共同點，
是 3 人都正在玩 Claude，
見面後一拍即合，
開始合作。

我們約定每週開會，
一次走多條路線，
開發不同類型產品。

目前已經完成 3 項產品，
其中 2 個的目標市場是國外，
先分享另一項產品。

▎Claude Code 新手村


我在玩 Claude 的過程中，
發現它的潛力後，
也想分享它給其他事業合夥人。

於是我做了一套 Claude Code 新手村，
用互動遊戲的方法，
快速教人學會 Claude 基本操作。

為了讓教學更完整，
我甚至買了一台 Windows 筆電，
特地為不同習慣的工作者，
規劃有效教學。

在研發過程，
我還跟 Claude 一起建立會員系統，
也串了信用卡、Apple Pay、ATM 等金流方案。

我也開放這套互動教學，
給幾位親友試用。
大家都順利安裝 Claude，
並做出自己的小作品網站。

其中有幾位太喜歡，
也主動付費升級。

近期，
我又用 Claude 大幅更新官方網站。

▎官網大翻新


我有個拖延許久的事，
就是定期更新官網。

官網中有許多日常更新：
諮詢案例、網站案例、演講歷程、自我介紹。

因為是自己寫的程式，
每次更新都很麻煩，
需要理解程式碼、手動改資料、上傳，
才能更新。

直到生日那週，
我反思自己事業瓶頸時，
忽然驚覺這件一直無法放手的事。

於是我決定交由 Claude 重構，
官網程式碼，全部重寫。

此外，
我還新增公司的後台系統，
包含：

案件管理、支出紀錄、報價單系統、
待辦清單、寫作靈感、流程知識庫、罐頭訊息。

我還額外做了常用工具庫，包含：
PDF 編輯器、圖片掃描轉 PDF、圖片批次壓縮。

最後，
我也把電子報訂閱，
嵌入在官方網站中。

還沒結束。

我近期正在做一套會員系統，
以及數位產品上架功能，
終於做了拖延好久的各種事。

在玩 Claude 的過程，
也讓我其他事業一起升級了。

▎遍地開花


我發現 Claude 不只能開發網站，
還能建立 APP，
這是我正在醞釀的小專案。

我的包租代管事業，
官網已經搭建完成，
甚至還做了冷氣經銷的頁面。

我最近去一間溫泉飯店談合作，
打算用 Claude 協助重構內部管理系統。

額外透露一個小彩蛋，
8/22（六）的閱讀串門子活動，
我會分享一個「線上書友互動小遊戲」，
效果非常驚艷。

如果説去年，
是包租代管事業改變了我，
今年的主軸，絕對是 Claude。

▎全面升級


訂閱 Claude 的月費，
我從 600 元，
已經升級到約 3000 元。

有了它以後，
我做到以前需要數百萬、
甚至數年才能做到的事。

然而我在社群上看見的，
多數專業工作者，
僅用它來產文、產圖，
還沒充分運用它的最強潛力。

這讓我激起一個，
自己醞釀好幾年的想法。

▎共學營


我一直有一個，
想要舉辦黑客松的念頭：

大家帶著點子來，
身邊有一群同樣熱情的人，
各自在現場開發，
同時也能相互交流。

而最後，
則分享今天的成果。

我超想看見這幅畫面。

於是我和夥伴討論後，
決定 2026.08.23（日）14:00-17:30，
舉辦一場 Claude Code 共學營。

這是入門款的活動，
我會展示迄今做過的網站、系統，
2 位夥伴也都到場。

此外，
如果你是完全不懂的小白，
我會帶你入門 Claude Code，
一起成為創造者。

如果你已經熟悉 Claude 了，
則可以到場開發，
最後在和大家交流。

這場收 25 人，
目前約剩 10 個名額，
請點擊「活動連結」報名。
折扣碼：SIDDBLUE10

不確定何時會辦下一次，
如果你還沒玩 Claude Code，
也想入門很久，
非常歡迎來這場活動，
突破你的思維上限。

這或許會是你人生中，
獲得過的最強槓桿。
